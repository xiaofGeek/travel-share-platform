# 版本兼容方案

版本以本机已成功运行的 `springboot-admin` 项目为基线，不采用未验证的最新版。

| 组件 | 锁定版本 | 说明 |
| --- | --- | --- |
| Java | 21.0.3 | 本机 IntelliJ 自带完整 JDK |
| Maven | 3.9.8 | 本机 IntelliJ 自带版本 |
| Spring Boot | 3.3.2 | 既有项目已验证 |
| MyBatis Plus | 3.5.7 | Spring Boot 3 starter |
| MySQL Server / Connector | 8.0.46 / 8.0.33 | 本机服务与兼容驱动 |
| Node.js / npm | 24.11.0 / 11.6.1 | 本机实际版本 |
| Vue / Router / Pinia | 3.3.4 / 4.2.2 / 2.0.30 | 既有项目基线 |
| Vite / Vue plugin | 6.4.3 / 5.2.4 | 已验证兼容 Node 24 |
| Element Plus | 2.11.1 | 既有项目已构建通过 |
| Axios / ECharts | 1.18.1 / 6.1.0 | 既有项目已构建通过 |

前后端依赖使用精确版本并提交锁文件。后端不使用 Java 预览特性；数据库使用 InnoDB、`utf8mb4` 和普通索引；项目不依赖 Docker、Redis、Elasticsearch、消息队列或云服务。
